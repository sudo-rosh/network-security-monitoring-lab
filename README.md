# Network Security Monitoring Lab

A hands-on cybersecurity project focused on building, securing, and investigating a small enterprise network.

## Project Overview

This project involves building a small enterprise network in Cisco Packet Tracer, progressively securing it, introducing controlled security incidents, investigating network traffic, and developing a Python-based traffic-analysis component.

The project follows this progression:

**Networking → Network Architecture → Network Security → Threat Modeling → Network Monitoring → Automation**

## Project Objectives

- Build a functioning enterprise-style network.
- Implement and test network security controls.
- Develop realistic security scenarios.
- Investigate network traffic using Wireshark.
- Develop a Python-based network traffic analyzer.
- Document the design decisions, testing, investigations, and findings.

## Project Structure

```text
phase-1/    Project definition & requirements
phase-2/    Baseline network
phase-3/    Network segmentation
phase-4/    Network security controls
phase-5/    Threat modeling & attack scenarios
phase-6/    Traffic analysis & investigation
phase-7/    Python network traffic analyzer
phase-8/    Final security assessment
```
